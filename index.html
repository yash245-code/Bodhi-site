Cortex strikes the ideal balance between raw desktop power and instant responsiveness. Built from scratch with modern web standards and native system bindings.

High-Precision Monaco Engine

Equipped with the battle-tested Monaco Editor engine. Enjoy multi-cursor editing, bracket colorization, minimap support, and syntax highlighting for 25+ languages.

  • TypeScript / JS
  • Python
  • Rust / Go
  • JSON / YAML

Native Dockable Terminal

Integrated xterm.js terminal with native node-pty acceleration. Run PowerShell, Command Prompt, or WSL with zero input latency and full ANSI color support.

  • PowerShell / WSL
  • Bi-directional IPC
  • Dockable Panel

Dynamic File Tree & Watcher

Multi-directory workspace management with real-time chokidar file system tracking. External file changes appear instantly in your workspace with zero manual refresh.

  • Inline Create/Rename
  • Folder Watcher
  • Dirty Buffer Tracking

100% Local & Privacy-First

Strict process isolation (contextIsolation: true). BUIMB Research guarantees zero keystroke telemetry, zero remote tracking, and direct client-to-API communication.

  • Zero Telemetry
  • Direct AI Keys
  • Local Storage

Instant Sub-Second Startup

Optimized Vite bundle with on-demand module resolution. Launches cleanly without hundreds of background services eating away your CPU and RAM.

  • < 750ms Launch
  • Low RAM footprint
  • Clean Lifecycle

Seamless Tab & Layout Manager

Multi-tab workspace with middle-click close, unsaved dot badges, keyboard navigation, breadcrumb path traversal, and customizable split-views.
